# 05 – Social Proof / Success Metrics

**Optimizely Reference**: “Stories of success” with big metrics (50% conversion lift, 400+ hours saved).

---

## Purpose
Make the economic impact concrete and memorable for judges.

## Layout
- Section heading + 3–4 large metric cards in a row
- Optional short quote or “pilot ready” statement below

## Content Spec

### Section Heading
```
The economic case is already clear
```

### Metric Cards

| Metric                        | Label                              |
|-------------------------------|------------------------------------|
| ₹4,200 Cr                     | Annual economic drag addressed     |
| ₹3.5 Lakh Cr                  | Procurement volume in scope        |
| 0.0%                          | False-positive safety mismatches   |
| < 50 ms                       | Target search latency (p95)        |

### Supporting Line
```
Built for pilot deployment at IOCL Mathura, ONGC Hazira, BPCL Mumbai and HPCL Visakhapatnam.
```

## Visual Notes
- Large bold numbers (terracotta or near-black)
- Small descriptive label underneath
- Soft card background or just clean typography on white
- Optional: subtle icon above each metric

## Implementation Notes
- Static for demo (hardcoded is fine).
- Make numbers animate on scroll into view if time permits (Framer Motion).
