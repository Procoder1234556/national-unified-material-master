# NUMM Landing Page – Design Instructions (Optimizely Style)

**Inspired by**: [Landingfolio – Optimizely](https://www.landingfolio.com/inspiration/post/optimizely)  
**Target**: Professional, high-trust SaaS landing page for Smart India Hackathon 2026 (SIH 26099)  
**Product**: National Unified Material Master (NUMM) – One Nation, One Material Code (ONMC)  
**Sponsoring Ministry**: Ministry of Petroleum & Natural Gas (MoPNG)

---

## Design Philosophy (Optimizely DNA)

- **Bold, benefit-first headlines** that speak to outcomes (growth, freedom, savings)
- **Generous white space** + strong visual hierarchy
- **Logo cloud** immediately after hero for instant trust
- **Feature sections** presented as clear “tools / paths”
- **Social proof with real metrics** (₹ impact, hours saved, % lift style)
- **Multiple strategic CTAs** (primary = Enter Dashboard / Live Demo)
- **Clean, modern, sovereign industrial aesthetic** (not playful startup)

### NUMM Color Adaptation (from existing DESIGN.md)
- Primary Action: `#E94344` (Terracotta)
- Deep Accent: `#9B121E` (Crimson)
- Secondary: `#5F978E` (Petroleum Sage)
- Text: Near-black `#141414` / `#1A1A1A`
- Backgrounds: Pure white + soft off-white `#F8F7F5`
- Borders: Subtle `#E5E2DE`

### Typography
- Headlines: Bold, tight tracking, large scale (clamp 2.5rem → 4.5rem)
- Body: Clean sans (Inter / system-ui), 16–18px, excellent readability
- Mono for codes / technical labels (ONMC codes, MESC, etc.)

### Overall Page Flow (Optimizely Structure)
1. **Hero** – Bold claim + primary CTA
2. **Logo Cloud** – Trusted by CPSEs / MoPNG
3. **Problem → Solution** (or “Tools to get you growing”)
4. **Feature Grid** (3–4 key capabilities)
5. **Social Proof / Success Metrics**
6. **Secondary CTA**
7. **Integrations / Standards** (MESC, UNSPSC, GeM, ASME)
8. **Final CTA + Footer**

---

## Success Criteria for SIH Judges
- Instantly communicates the ₹4,200 Cr problem and sovereign solution
- Looks production-ready (not a student project)
- Clear path to “Enter Dashboard” / “Watch Live Demo”
- Mobile responsive
