# 03 – Logo Cloud / Trust Bar

## Purpose

Show institutional credibility immediately after the hero.

## Layout Details

- Full width
- Background color: `#F8F7F5`
- Vertical padding: 64px top and bottom
- Content centered
- Max width: 1100px

## Exact Content

### Small Heading

```
Designed under the vision of Ministry of Petroleum & Natural Gas
```

- Font size: 14px
- Color: `#6B6B6B`
- Text align: center
- Margin bottom: 32px

### Logo / Name Row

Display these names in a horizontal row (or wrapped row on mobile):

IOCL ONGC BPCL HPCL GAIL OIL EIL NRL MRPL CPCL

- Each name: Font weight 600, font size 15px, color `#4A4A4A`
- Gap between names: 40px
- On hover: color becomes `#E94344`

## Image Recommendation

- Prefer clean text names (no real logos needed)
- If you want logos: use simple gray SVG or PNG logos of the CPSEs
- Do not use colorful logos that break the clean look

## Effects

- Section fades in + moves up 20px when it enters the viewport
- Individual names can have a very light opacity change on hover

## Mobile

- Allow the row to wrap into 2 lines
- Reduce gap to 24px
